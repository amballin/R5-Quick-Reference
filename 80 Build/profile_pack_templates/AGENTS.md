# Private Profile Pack Working Agreements

- Treat this repository as private owner configuration for the Canon EOS R5 Camera Reference application.
- Keep `profile-pack.yaml` at the repository root and preserve its immutable `pack_id`.
- Keep every canonical source inside this repository at the manifest-declared path.
- Do not copy application code, schemas, validators, templates, Canon definitions, or credentials into this pack.
- Validate changes through the compatible application checkout before committing or sharing generated output.
- Include this `AGENTS.md` in the repository's initial commit and preserve it as project source.
- Do not publish unreleased profiles, verification evidence, machine-local paths, credentials, backups, or local Camera Lab state.
- Keep Git commits, remotes, pushes, recovery, and handoff independent from the application repository.
