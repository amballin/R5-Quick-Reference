# Fv (Flexible Priority)

## What is Fv?

Fv (Flexible Priority) is Canon's Flexible Priority shooting mode. Unlike traditional exposure modes, Fv allows each exposure parameter to be independently set to either **Manual** or **AUTO**.

This lets you move between fully automatic exposure, selective control, and manual exposure without switching among P, Av, Tv, and M.

## Parameters

| Setting | Camera-controlled state | Photographer-controlled state |
|---|---|---|
| Shutter Speed | AUTO | Chosen shutter speed |
| Aperture | AUTO | Chosen aperture |
| ISO | AUTO | Chosen ISO |
| Exposure Compensation | ±0 | Chosen compensation |

Shutter speed, aperture, and ISO may be controlled independently. Setting one manually does not require the others to be manual.

## How to Change Settings

1. If **LOCK** is displayed or the dials do not respond, press the **Multi-function Lock button** once to unlock the configured controls.
2. Turn the **Top Rear Dial (Quick Control Dial 2)** to select **Shutter Speed**, **Aperture**, **ISO**, or the **Exposure Compensation** indicator. The Main Dial marker appears beside the selected item.
3. Turn the **Main Dial** to set the selected value.
4. Press the **Erase (trash-can) button** to return the selected shutter speed, aperture, or ISO setting to **AUTO**, or exposure compensation to **±0**.

## Display Example

| Parameter | Displayed Value |
|---|---:|
| Tv | 1/1000 |
| Av | F5.6 |
| ISO | 400 |
| EC | +0.3 |

> **Note:** It is normal for shutter speed, aperture, and ISO all to begin at **AUTO**. AUTO values are underlined on the camera display.

## When LOCK Appears

The Multi-function Lock applies to configured physical controls, not to individual Fv parameters. Under **Set-up > Multi function lock**, the camera can be configured to lock the Main Dial, Quick Control dials, joystick, control ring, and/or touchscreen. Pressing the Multi-function Lock button toggles those selected controls between locked and unlocked.

In Fv, locking the Top Rear Dial can prevent selection of another exposure parameter, while locking the Main Dial can prevent changing the selected value. Unlock the controls to make the adjustment, then lock them again if protection from accidental changes is useful.

## Common Configurations

| Configuration | Tv | Av | ISO | Result |
|---|---:|---:|---:|---|
| P Mode Equivalent | AUTO | AUTO | AUTO | Camera controls everything. |
| Sports | 1/2000 | AUTO | AUTO | Locks shutter speed. The camera adjusts aperture and ISO. |
| Portrait | AUTO | F2.8 | AUTO | Locks aperture. The camera adjusts shutter speed and ISO. |
| Landscape | AUTO | F11 | 100 | Locks aperture and ISO. The camera adjusts shutter speed. |
| Manual + Auto ISO | 1/1000 | F5.6 | AUTO | The photographer controls motion blur and depth of field while Auto ISO maintains exposure. Useful for wildlife, birds, sports, and action. |

## Fv Compared to Traditional Modes

| Traditional Mode | Equivalent in Fv |
|---|---|
| P | Tv=AUTO, Av=AUTO, ISO=AUTO |
| Av | Tv=AUTO, Av=Manual, ISO=AUTO |
| Tv | Tv=Manual, Av=AUTO, ISO=AUTO |
| M + Auto ISO | Tv=Manual, Av=Manual, ISO=AUTO |
| Manual | Tv=Manual, Av=Manual, ISO=Manual |

## Why Use Fv?

Fv allows photographers to stay in a single shooting mode while deciding which exposure parameters are automatic and which are manually controlled. It effectively replaces frequent switching among P, Av, Tv, and much of M mode while preserving direct control whenever it is needed.
