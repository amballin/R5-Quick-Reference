Checklist

  • Confirm Screen info. settings Mode 5 is enabled for quick configuration with Q
  • Save named camera-settings files to a card after registering C1-C3

Watch For

  • Noise reduction accidentally enabled
  • JPEG-only specialty modes left on
  • 1.6× crop left enabled after a distant-subject session
  • Lens-specific focus options not available

Common Mistakes

  • Treating setup items like field profile choices
  • Leaving a specialty mode enabled after testing
  • Treating 1.6× crop as added optical reach
  • Letting temporary C1-C3 changes overwrite registered settings

Notes

  • No Cx foundation is declared. Every Δ marks a target to verify or set on the camera. Colored setting values use the matching My Menu tab; white values use Quick Control, dials, buttons, or normal menu access.
  • Shared operational defaults use Case A (Auto). C1 Wildlife is a separate registered target using the project-customized Case 1 preset; verify both after a reset or loading a saved camera-settings file.
  • Keep Screen info. settings modes 1–5 enabled. Mode 5 provides the full Quick Control screen for reviewing and changing camera settings quickly with Q; INFO cycles through the enabled displays. Camera menu: Shooting 7 > Shooting info. disp. > Screen info. settings.
  • Highlight tools stay on because exposure warnings are useful in the field.
  • Keep Cropping/aspect ratio at Full-frame. Temporarily use 1.6× for a distant, predictably framed subject when the tighter view helps, then restore Full-frame. RF-S and adapted EF-S lenses force 1.6× while attached.
  • Keep MF Peaking on as a manual-focus aid. Use Level Low and Color Red as the starting display; magnification remains the final check for critical focus because peaking indicates contrast edges rather than guaranteeing exact focus.
  • Keep Auto update disabled so temporary changes made while using C1, C2, or C3 do not silently replace the registered subject setup.
  • Use Save/load cam settings on card for named complete configurations. For example, keep one file with C3 registered for People and another with C3 registered for Landscape; loading a file restores the complete saved camera configuration, not only C3.
  • High ISO Noise Reduction stays off because Lightroom/Topaz handles RAW cleanup better.
  • Long Exposure NR can reduce hot pixels and fixed-pattern noise in selected multi-second exposures, but its additional dark-frame wait interrupts shooting; leave it off when cadence matters.
  • Continuous AF is off because it can drain battery by focusing when you are not shooting.
  • High speed display is enabled to make regular High Speed Continuous bursts easier to follow. It does not increase the burst rate and may pause under unsupported shooting conditions.
  • Electronic full-time MF is off because it is not useful for your lens.
  • IBIS High Resolution Shot is off because it is a static-scene specialty mode with very large JPEG output.
