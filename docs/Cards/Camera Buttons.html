Checklist

  • Practice back-button AF before a critical shoot.
  • Use SET to choose eye priority before AF-ON when Face + Tracking is active.
  • Verify the C1-C3 registrations on the camera.
  • Use the linked deep dive for My Menu: SWITCH and My Menu: AF Case.
  • Confirm Manual + Auto ISO before using exposure compensation.
  • Recheck assignments after a reset or firmware update.

Watch For

  • Lock can disable configured dials, joystick, control ring, touchscreen across shooting modes
  • AE Lock: 1-Point AF does not use Subject Detection or Eye Detection for that AF action; the stored profile settings remain unchanged
  • SET has no effect when the active AF method cannot use Eye detection
  • AE Lock remembers the last 1-Point AF position; press the joystick straight in when recentering is needed
  • Exposure Compensation on Control Ring requires Auto ISO in Manual exposure

Common Mistakes

  • Expecting shutter half-press to autofocus after enabling back-button AF
  • Pressing AF-ON and AE Lock together instead of choosing one AF behavior
  • Expecting Eye Detection to operate with the 1-Point AF override
  • Expecting SET to toggle Eye detection while 1-Point AF or Spot AF is active
  • Assuming C1, C2, or C3 contains its documented profile without verifying the registration
